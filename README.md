# homebrew-pulldeck

Homebrew tap for [PullDeck](https://pulldeck.dev) — a native macOS menu-bar app
that shows your GitHub pull requests, sorted by priority and flow signals.

## Install

```bash
brew install --cask lumargo/pulldeck/pulldeck
```

The cask is bumped automatically by PullDeck's `scripts/release.sh` on every release.
